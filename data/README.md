# Dataset attribution

`student_dropout.csv` is the UCI Machine Learning Repository dataset **Predict Students' Dropout and Academic Success**, created by Valentim Realinho, Mónica Vieira Martins, Jorge Machado, and Luís Baptista.

- UCI dataset ID: 697
- DOI: <https://doi.org/10.24432/C5MC89>
- Repository page: <https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success>
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- Included file SHA-256: `3ef126de5cefff26eb11fbb4237f1a1401cb64b488e2f1d598c23cedeb4c45ae`

The file contains 4,424 rows, 36 input features, and the three-class target `Dropout`, `Enrolled`, or `Graduate`. It is redistributed without modification apart from its repository filename.

Suggested citation:

> Realinho, V., Vieira Martins, M., Machado, J., & Baptista, L. (2021). Predict Students' Dropout and Academic Success [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5MC89
